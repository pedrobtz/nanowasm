## What this package is

`nanowasm` is an R package for running WebAssembly modules from R with no system dependencies. The intended design:

- Load modules from raw vectors or files and call their exported functions from R.
- Execute them with a **bundled copy of the `toywasm` interpreter** (C sources vendored into the package), so installing needs no system Wasm runtime, extra toolchain or download.
- Pass R vectors into a module's linear memory and read them back through a small, explicit API.
- Let R functions be supplied as imports so a module can call back into the R session.
- Sandbox modules: no filesystem, network or environment access unless an import grants it. Traps, stack exhaustion and memory growth surface as structured R conditions, with configurable limits.

**Current state:** only the usethis/pkgdown skeleton exists. `DESCRIPTION` Title/Description/Authors@R and the README are still placeholders, there is no `src/` yet, and the only test is the template one. The description above is the target, not what's implemented.

## Commands

Standard devtools workflow, run from the repo root:

```sh
Rscript -e 'devtools::document()'                         # regenerate NAMESPACE + man/ from roxygen
Rscript -e 'devtools::test()'                             # all tests
Rscript -e 'devtools::test(filter = "nanowasm")'          # one file: tests/testthat/test-nanowasm.R
Rscript -e 'testthat::test_file("tests/testthat/test-nanowasm.R")'  # alt; needs package loaded/installed
Rscript -e 'devtools::check()'                            # full R CMD check
Rscript -e 'pkgdown::build_site()'                        # site into docs/ (gitignored)
```

Once C code exists in `src/`, `devtools::load_all()` / `devtools::test()` recompile it; use `devtools::clean_dll()` to force a clean rebuild.

## Conventions

- `NAMESPACE` is generated by roxygen2 (markdown enabled) — edit roxygen tags, then `devtools::document()`; never hand-edit `NAMESPACE` or `man/`.
- testthat edition 3.
- Package-level imports/`useDynLib` go in the `## usethis namespace` block of `R/nanowasm-package.R`.
- Add user-facing changes to `NEWS.md` under the development-version heading.
- The package targets CRAN. When vendoring `toywasm`, its copyright holders must be credited (Authors@R `cph` role and/or `inst/COPYRIGHTS`) and its license kept compatible with MIT.

## CI

Workflows in `.github/workflows/` mostly call reusable workflows from `pedrobtz/r-actions@v1`:

- **R-CMD-check**: runs a `quick` profile on PR pushes and a `full` profile on pushes to `main`. Adding the `full-ci` label to a PR runs the full profile there.
- **coverage**: updates `.github/badges/coverage.svg` on `main` (that path is ignored as a trigger).
- **pkgdown**: builds the site and deploys it to the `gh-pages` branch (https://pedrobtz.github.io/nanowasm/).
